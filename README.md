# R-aspirateur2000

## Objectif

L'objectif est de faire un robot fonctionnel et fiable pour la Coupe de France de robotique 2026


## arborescence des fichiers

- src : contient le code et les plan des pieces 3D pour concevoir un robot autonome pour la coupe
- doc : la doc qui explique comment monté le robot
- install : doit contenir les scripts pour setup le code du robot$
